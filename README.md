# 🏮 运河风物志 Canal Delights

> 用 Python Turtle 绘制大运河沿线城市节气美食图鉴

一个用代码绘制的美食文化画卷，展现大运河沿线五座城市的节气饮食之美。

---

## ✨ 项目特色

- **五城二十味**：覆盖北京、天津、扬州、苏州、杭州五座运河名城，每城四道代表性美食
- **中国风视觉**：朱砂红、赭石、青碧、靛蓝、茶绿，传统配色呈现东方美学
- **行舟交互**：带惯性的小船、鼠标长按航行、船尾水花和跟随定位标的城市预览
- **动态界面**：卷轴转场、城市呼吸动效、悬浮/按下/禁用状态与翻页图鉴
- **双渲染后端**：默认 Canvas 批量加速，可在设置页即时切换纯 Turtle，也可通过命令行强制兼容模式
- **代码演奏 BGM**：五声音阶曲谱内嵌于代码，运行时实时合成，不依赖任何音频文件
- **可调设置**：主音量实时控制 BGM，音效滑杆为后续交互音效预留接口

## 🛠️ 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                       应用层 (app.py)                         │
├─────────────────────────────────────────────────────────────┤
│  状态与交互层   │  内容与场景层     │  动画与物理层               │
├─────────────────────────────────────────────────────────────┤
│  业务层：五城二十味（声明式 DSL 数据）                          │
├─────────────────────────────────────────────────────────────┤
│  核心层：DSL 解析器 + 双渲染后端 + 动画时钟                    │
├─────────────────────────────────────────────────────────────┤
│  Python Turtle 绘图库                                         │
└─────────────────────────────────────────────────────────────┘
```

**核心设计理念：** 在 Turtle 之上构建微型游戏引擎，用声明式数据驱动渲染，类似 React 的"数据驱动视图"模式。

## 🚀 快速开始

### 环境要求

- Python 3.9+
- 无需额外依赖（Turtle 为标准库）

### 运行程序

```bash
# 首次使用：以可编辑方式安装本项目（没有第三方运行时依赖）
python -m pip install -e .

# 启动互动绘卷
python -m canal_delights
# 或：python run.py

# 强制使用纯 Turtle 后端（教学核验/兼容模式）
python -m canal_delights --renderer pure

# 默认启用批量 Canvas 加速后端
python -m canal_delights --renderer accelerated
```

## ⌨️ 操作指南

| 按键 | 功能 |
|------|------|
| 按住 `←` `→` | 在地图驾驶小船；在城市场景切换美食；在图鉴翻页 |
| 鼠标长按地图箭头 | 持续驾驶小船，松开后惯性滑行 |
| `Enter` | 进入、查看或完成品鉴 |
| `B` | 在地图打开图鉴，或关闭图鉴 |
| `H` | 显示/隐藏帮助 |
| `ESC` | 返回上一级 |

主页左下角的悬浮书形按钮打开图鉴，右上角的设置按钮可切换渲染模式并调整预留音量参数。
