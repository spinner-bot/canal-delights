# 🏮 运河四季·Turtle 美食绘卷

> 用 Python Turtle 绘制大运河沿线城市节气美食图鉴

一个用代码绘制的美食文化画卷，展现大运河沿线五座城市的节气饮食之美。

---

## ✨ 项目特色

- **五城十味**：覆盖北京、天津、扬州、苏州、杭州五座运河名城，每城精选两道代表性美食
- **中国风视觉**：朱砂红、赭石、青碧、靛蓝、茶绿，传统配色呈现东方美学
- **动态交互**：开场动画、场景切换、食物绘制动画，让画面"活"起来
- **工程化架构**：面向对象设计 + 事件驱动 + 声明式渲染，代码即艺术

## 🛠️ 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                        应用层 (main.py)                       │
├─────────────────────────────────────────────────────────────┤
│  UI层          │  场景层          │  动画层                    │
│  Menu / HUD    │  SceneManager    │  Animator                  │
├─────────────────────────────────────────────────────────────┤
│  业务层：5个城市模块（声明式场景数据）                          │
├─────────────────────────────────────────────────────────────┤
│  核心层：绘图引擎 + 事件总线 + 动画引擎                        │
├─────────────────────────────────────────────────────────────┤
│  Python Turtle 绘图库                                         │
└─────────────────────────────────────────────────────────────┘
```

**核心设计理念：** 在 Turtle 之上构建微型游戏引擎，用声明式数据驱动渲染，类似 React 的"数据驱动视图"模式。

## 🚀 快速开始

### 环境要求

- Python 3.6+
- 无需额外依赖（Turtle 为标准库）

### 运行程序

```bash
# 克隆项目
git clone https://github.com/spinner-bot/canal-delights.git
cd canal-delights

# 运行
cd src
python main.py
```

## ⌨️ 操作指南

| 按键 | 功能 |
|------|------|
| `←` `→` | 切换城市 |
| `↑` `↓` | 切换当前城市的美食 |
| `空格` | 重播当前美食绘制动画 |
| `F1` | 显示/隐藏帮助 |
| `F5` | 回到主菜单 |
| `ESC` | 退出程序 |
