# 《运河四季·Turtle 美食绘卷》项目设计文档

> 用 Python Turtle 绘制大运河沿线城市节气美食图鉴

---

## 一、项目概述

### 1.1 项目背景
本项目受大运河文化节组委会委托，创作一幅展现运河沿线城市节气美食的电子绘卷。通过 Python Turtle 绘图库，以编程艺术的形式呈现大运河文化带的饮食文化魅力。

### 1.2 设计理念
- **文化传承**：以二十四节气为线索，展现运河沿线城市的时令美食
- **技术美学**：用代码绘制精美画面，融合编程逻辑与艺术表达
- **交互体验**：打破静态绘图，实现可交互的动态绘卷

### 1.3 技术亮点（远超作业要求）

| 维度 | 作业要求 | 本项目实现 |
|------|----------|------------|
| 城市数量 | 未明确 | 5城全覆盖（北京、天津、扬州、苏州、杭州） |
| 美食数量 | 至少3种 | 10种（每城2道代表性美食） |
| 代码架构 | 无要求 | 面向对象设计，模块化架构 |
| 视觉效果 | 颜色填充 | 渐变色彩、中国风配色、精美细节 |
| 动画效果 | 简单动态 | 开场动画、场景切换、食物绘制动画 |
| 交互功能 | 可选 | 完整交互系统（键盘+菜单） |
| 文字标注 | 简单标注 | 艺术字体、节气说明、文化背景 |

## 三、城市与美食规划

### 3.1 五城美食一览

| 城市 | 美食一 | 美食二 | 主题色 | 文化关键词 |
|------|--------|--------|--------|------------|
| **北京** | 北京烤鸭 | 中秋月饼 | 朱红 #C9302C | 皇城气派、京味文化 |
| **天津** | 狗不理包子 | 天津麻花 | 赭石 #8B4513 | 市井烟火、码头文化 |
| **扬州** | 蟹粉狮子头 | 蟹黄汤包 | 青碧 #2E8B57 | 淮扬精致、文人雅趣 |
| **苏州** | 桂花糕 | 松鼠桂鱼 | 靛蓝 #4169E1 | 园林秀美、苏工精细 |
| **杭州** | 龙井茶 | 西湖醋鱼 | 茶绿 #6B8E23 | 诗意江南、茶韵悠长 |

### 3.2 美食绘制细节设计

#### 北京烤鸭
- 枣红色鸭身，油亮光泽（渐变效果）
- 切片摆盘，配以葱丝、黄瓜条、甜面酱
- 荷叶饼卷起的状态
- 节气标注：「秋冬·贴膘」

#### 狗不理包子
- 十八道褶子的细节
- 热气腾腾的效果（半透明叠加）
- 竹蒸笼盛放
- 节气标注：「四季·早餐」

#### 蟹粉狮子头
- 大而圆的狮子头，金黄色泽
- 清汤背景，青菜点缀
- 陶钵盛器
- 节气标注：「秋·蟹肥」

#### 桂花糕
- 淡黄色糕体，桂花点缀
- 菱形切块，堆叠摆放
- 青花瓷盘
- 节气标注：「秋·桂香」

#### 龙井茶
- 透明玻璃杯中的茶汤（黄绿色渐变）
- 茶叶舒展的姿态
- 茶烟袅袅（动画效果）
- 节气标注：「春·明前」

## 六、实现计划

### 6.1 开发阶段

| 阶段 | 任务 | 预计代码量 | 优先级 |
|------|------|------------|--------|
| P0 | 核心引擎 + 基础框架 | ~500行 | 最高 |
| P1 | 5个城市美食绘制 | ~1000行 | 高 |
| P2 | 交互系统 | ~300行 | 高 |
| P3 | 动画效果 | ~400行 | 中 |
| P4 | UI完善 + 测试 | ~300行 | 中 |

### 6.2 关键技术点

1. **Turtle 性能优化**
   - 使用 `tracer(0, 0)` 关闭自动刷新
   - 手动调用 `update()` 控制刷新时机
   - 复杂图形预计算坐标

2. **动画实现**
   - 基于帧的动画系统
   - 缓动函数（ease-in-out）
   - 定时器控制

3. **代码复用**
   - 抽象公共绘图方法
   - 美食基类统一接口
   - 配置驱动的城市数据
