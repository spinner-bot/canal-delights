> 用 Python Turtle 绘制大运河沿线城市节气美食图鉴

---

## 一、项目概述

### 1.1 项目背景
本项目受大运河文化节组委会委托，创作一幅展现运河沿线城市节气美食的电子绘卷。通过 Python Turtle 绘图库，以编程艺术的形式呈现大运河文化带的饮食文化魅力。

### 1.2 设计理念
- **文化传承**：以二十四节气为线索，展现运河沿线城市的时令美食
- **技术美学**：用代码绘制精美画面，融合编程逻辑与艺术表达
- **交互体验**：打破静态绘图，实现可交互的动态绘卷

### 1.3 技术亮点（远超作业要求）

| 维度 | 作业要求 | 本项目实现 |
|------|----------|------------|
| 城市数量 | 未明确 | 5城全覆盖（北京、天津、扬州、苏州、杭州） |
| 美食数量 | 至少3种 | 10种（每城2道代表性美食） |
| 代码架构 | 无要求 | 面向对象设计，模块化架构 |
| 视觉效果 | 颜色填充 | 渐变色彩、中国风配色、精美细节 |
| 动画效果 | 简单动态 | 开场动画、场景切换、食物绘制动画 |
| 交互功能 | 可选 | 完整交互系统（键盘+菜单） |
| 文字标注 | 简单标注 | 艺术字体、节气说明、文化背景 |

#### 2.4.3 模拟 JS 的"事件系统" → 事件总线（EventBus）

```python
class EventBus:
    """事件总线 - 解耦组件间通信"""
    
    def __init__(self):
        self.handlers = {}
    
    def on(self, event, handler):
        """注册事件监听"""
        self.handlers.setdefault(event, []).append(handler)
    
    def off(self, event, handler=None):
        """移除事件监听"""
        if handler:
            self.handlers[event].remove(handler)
        else:
            self.handlers.pop(event, None)
    
    def emit(self, event, data=None):
        """触发事件"""
        for handler in self.handlers.get(event, []):
            handler(data)

# 使用示例
events = EventBus()
events.on('city_changed', lambda city: print(f"切换到: {city}"))
events.on('food_selected', lambda food: animate_food(food))
events.emit('city_changed', '北京')
```

#### 2.4.4 模拟 CSS/JS 的"动画" → 动画引擎（Animator）

```python
class Animator:
    """动画引擎 - 基于 ontimer 的帧动画系统"""
    
    EASING = {
        'linear': lambda t: t,
        'ease-in': lambda t: t * t,
        'ease-out': lambda t: t * (2 - t),
        'ease-in-out': lambda t: t * t * (3 - 2 * t),
        'bounce': lambda t: ...  # 弹跳效果
    }
    
    def animate(self, duration, callback, easing='ease-in-out', on_complete=None):
        """执行动画"""
        start_time = time.time()
        
        def tick():
            elapsed = time.time() - start_time
            progress = min(elapsed / duration, 1.0)
            eased_progress = self.EASING[easing](progress)
            
            callback(eased_progress)
            
            if progress < 1.0:
                self.screen.ontimer(tick, 16)  # ~60fps
            elif on_complete:
                on_complete()
        
        tick()
    
    def fade_in(self, element, duration=0.5):
        """淡入动画"""
        self.animate(duration, lambda t: element.set_opacity(t))
    
    def slide_to(self, element, target_x, target_y, duration=0.3):
        """滑动动画"""
        start_x, start_y = element.position
        self.animate(duration, lambda t: element.move_to(
            start_x + (target_x - start_x) * t,
            start_y + (target_y - start_y) * t
        ))
```

#### 2.4.6 架构优势

通过这套抽象层，我们实现了：

1. **声明式 UI** — 用数据描述界面，而非一步步指挥画笔
2. **样式与逻辑分离** — 修改主题不需要改动绘图代码
3. **可测试** — 场景数据可以独立于 Turtle 验证
4. **易扩展** — 新增城市/美食只需添加数据配置
5. **可复用** — 绘图引擎可用于其他 Turtle 项目

> **本质上：我们用 Python 在 Turtle 之上构建了一个微型游戏引擎。**

## 六、实现计划

### 6.1 开发阶段

| 阶段 | 任务 | 预计代码量 | 优先级 |
|------|------|------------|--------|
| P0 | 配置系统 + 事件总线 + 绘图引擎 | ~500行 | 最高 |
| P1 | 动画引擎 + 场景管理器 + 输入处理 | ~450行 | 最高 |
| P2 | UI 系统（开场动画、菜单、HUD） | ~370行 | 高 |
| P3 | 5个城市美食绘制 | ~1000行 | 高 |
| P4 | App 主类组装 + 集成调试 | ~130行 | 高 |
| P5 | 视觉打磨 + 动画调优 + 测试 | ~550行 | 中 |

### 6.2 关键技术点

1. **Turtle 性能优化**
   - `tracer(0, 0)` 关闭自动刷新，手动 `update()` 控制帧
   - 复杂图形预计算坐标，避免实时计算
   - 双缓冲减少闪烁

2. **声明式渲染管线**
   - 场景数据 → 渲染器分发 → Turtle 绘制
   - 样式解析 → 主题变量替换 → 最终参数
   - 类似 React 的"数据驱动视图"模式

3. **动画系统**
   - 基于 `ontimer` 的帧调度（~60fps）
   - 缓动函数库（linear / ease-in / ease-out / bounce）
   - 支持动画编排（顺序、并行、链式）

4. **代码复用与扩展**
   - 美食基类统一接口，新增美食只需实现 `get_scene_data()`
   - 配置驱动：主题、配色、间距全部集中管理
   - 事件总线解耦各模块依赖
